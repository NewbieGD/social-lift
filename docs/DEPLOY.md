# Деплой «Социального лифта»

Схема: код лежит в одном репозитории GitHub. Фронтенд (игра) собирается GitHub Actions и публикуется на GitHub Pages. Бэкенд собирается из того же репозитория на Amvera по `amvera.yml` и `backend/Dockerfile`. База — управляемый PostgreSQL на Amvera.

## 1. Приложение ВКонтакте

1. В кабинете разработчика создайте новое приложение типа «Игра».
2. В разделе «Разработка → Ключи доступа» скопируйте: ID приложения, защищённый ключ, сервисный ключ доступа. Никому их не показывайте и не кладите в код.
3. В разделе «Размещение» укажите URL запуска для всех платформ: `https://<github-логин>.github.io/social-lift/`.
4. Приложение не публикуйте: пока оно выключено, его могут запускать администраторы по ссылке `https://vk.com/app<ID>`.

## 2. База данных на Amvera

1. «PostgreSQL» → «Создать базу данных», тариф не ниже «Начальный».
2. Имя БД, например `sociallift`; пользователь, например `sociallift`; надёжный пароль. Имена `postgres` заняты.
3. После запуска на странице «Инфо» найдите внутреннее имя хоста вида `amvera-<логин>-cnpg-<проект>-rw`.

Строка подключения:

```
postgresql://<пользователь>:<пароль>@amvera-<логин>-cnpg-<проект>-rw:5432/<имя_бд>
```

## 3. Бэкенд на Amvera

1. «Приложения» → «Создать», тариф не ниже «Начальный». Окружение подхватится из `amvera.yml` (Docker).
2. Вкладка «Репозиторий» → подключить GitHub. Нужен токен GitHub (Settings → Developer settings → Personal access tokens). Выберите репозиторий `social-lift` и ветку `main`.
3. Вкладка «Переменные» (секреты добавлять как «Секрет»):

| Имя | Значение | Тип |
| --- | --- | --- |
| `APP_ENV` | `production` | переменная |
| `VK_APP_ID` | ID приложения VK | переменная |
| `VK_SECRET_KEY` | защищённый ключ VK | секрет |
| `VK_SERVICE_TOKEN` | сервисный ключ VK | секрет |
| `DATABASE_URL` | строка подключения из п. 2 | секрет |
| `RUN_SIGNING_SECRET` | случайная строка от 32 символов | секрет |
| `ALLOWED_ORIGINS` | `https://<github-логин>.github.io` | переменная |
| `TERMS_VERSION` | `1` | переменная |
| `ADS_ENABLED` | `0` (включить `1` после оферты рекламы) | переменная |
| `ADS_MIN_RUNS_BEFORE` / `ADS_EVERY_N_RUNS` / `ADS_MIN_INTERVAL_SEC` | `1` / `2` / `90` (необязательные) | переменная |

4. «Настройки» → включить бесплатное доменное имя. Проверка: `https://<домен>/api/health` отвечает `{"ok":true}`.
5. При старте контейнер сам применяет миграции (`alembic upgrade head`). Если переменные заданы неправильно, сервер не запустится и напишет причину в логах.

## 4. Фронтенд

1. В `frontend/src/config.ts` укажите `API_BASE_URL` = домен Amvera без `/` на конце.
2. Закоммитьте. GitHub Actions соберёт игру и опубликует на Pages.

## 5. Проверка

Откройте `https://vk.com/app<ID>` с аккаунта администратора. Ожидается: экран согласия, после принятия — игра; после проигрыша на экране итогов видно место за неделю и за всё время.

## Перед отправкой на модерацию

1. В панели приложения укажите ссылки на документы: `https://<github-логин>.github.io/social-lift/terms.html` и `.../privacy.html`.
2. В сообществе игры, раздел «Информация», укажите владельца (ФИО или ИП) и контакт.
3. Примите оферту рекламы https://dev.vk.ru/ru/apps-offer-ad, включите монетизацию в панели и поставьте в Amvera `ADS_ENABLED=1`. Перезапуск сервера включит рекламу без новой версии игры.
4. Загрузите иконку, обложку и скриншоты (`docs/CATALOG_ASSETS.md`).
5. Проверьте игру на Android, iOS, m.vk.ru и vk.com.

## Обязанности владельца

- Отвечать на обращения администрации VK не позднее 3 дней (п. 4.1.7 правил).
- Отвечать игрокам не позднее 7 дней (п. 2.4.1).
- Перед публикацией принять оферту рекламы: https://dev.vk.ru/ru/apps-offer-ad (п. 5.1.2).

## Локальный запуск бэкенда

```bash
cd backend
python -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt
cp .env.example .env   # и экспортируйте переменные
pytest -q
APP_ENV=development DEV_AUTH_BYPASS=1 uvicorn app.main:app --reload
```


## Покупки за голоса ВКонтакте

1. В панели разработчика откройте приложение, раздел **«Платежи»** (настройки приложения), и укажите **адрес для уведомлений**: `https://sociallift1-vkgamer.mia0.amvera.tech/api/vk/payments` (подставьте адрес своего сервера). Ключ подписи — тот же защищённый ключ приложения, что уже записан в переменной `VK_SECRET_KEY`.
2. Пока приложение не прошло проверку ВКонтакте, платежи работают в тестовом режиме. Добавьте в список тестеров аккаунты, которыми будете проверять (у каждого должен быть хотя бы 1 голос; в тестовом режиме голоса не списываются).
3. Новая миграция `0012` создаёт таблицу заказов. Выкладывайте сначала сервер.
4. Так как условия соглашения изменились (покупки), поставьте в Amvera `TERMS_VERSION=2`: игроки увидят согласие ещё раз.
5. Проверка: откройте «Стили» → «Премиум» на Android или в браузере ВКонтакте, нажмите «Купить». На iPhone вкладка «Премиум» скрыта.
6. Цена и состав покупок заданы на сервере (`backend/app/cosmetics.py`, `PRODUCTS`). Название товара для окна покупки не длиннее 48 символов.

## Реклама

Если переменной `ADS_ENABLED` нет в списке переменных Amvera, реклама выключена. Добавьте `ADS_ENABLED` = `1` (этап «Запуск») после принятия оферты рекламы и перезапустите сервер.


## Дуэли со ставкой, чат (жалобы и блокировки), награды

1. Новая миграция `0013` добавляет таблицы блокировок и жалоб в чате и колонку со списком побеждённых в серии дуэлей. Выкладывайте сначала сервер и дождитесь успешного запуска миграции.
2. Условия соглашения и политики снова изменились (ставки в дуэлях, жалобы в чате): увеличьте `TERMS_VERSION` ещё на единицу (если стоит 2, поставьте 3).
3. Чтобы читать жалобы на сообщения чата, добавьте переменную `ADMIN_KEY` (любая длинная случайная строка) и открывайте список запросом `GET /api/admin/chat-reports` с заголовком `X-Admin-Key: <значение>`. Без переменной список выключен.
4. Ставка в дуэли: `DUEL_STAKE` в `backend/app/services/game.py` (500 монет). Пороги жалоб: `CHAT_REPORT_HIDE` (3 жалобы убирают сообщение) и `CHAT_REPORT_MUTE` (5 игроков за сутки дают запрет писать на час, `CHAT_MUTE_SEC`) в `backend/app/duel_ws.py`. Запрет писать хранится в памяти и сбрасывается при перезапуске.
